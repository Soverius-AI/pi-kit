# pi-kit

pi-kit is a workspace for the [pi](https://github.com/earendil-works/pi) coding agent. A NestJS backend runs pi's SDK
in-process and streams runs to an Angular interface over [AG-UI](https://docs.ag-ui.com) and CopilotKit. The interface
runs in the Electron desktop app, a local browser, or a paired phone.

A service host owns the backend and can keep it running without an open desktop app. Server installations include the
host and CLI without Electron. Conversation history stays in pi's session files; pi-kit stores application metadata,
review state, and background-agent state separately.

These pages describe the implementation in this repository: how to run it, how the components fit together, and where
their behavior is defined. Design proposals and research are kept outside the published site in `doc/designs/`.

## API and source

- `doc/api/openapi.yaml` is the backend HTTP contract, regenerated by `pnpm run api:openapi`.
- The implementation and its tests define behavior. Library `README.md` files and source comments provide local context.

## Working on the site

```bash
cd doc
pnpm install
pnpm start      # live preview on http://localhost:3000/pi-kit/
pnpm build      # static output in doc/build/
```

The documentation package is outside the Nx workspace and has its own dependencies. Pages use CommonMark `.md` files;
`.mdx` is available for JSX content. Diagrams use Mermaid code blocks.
