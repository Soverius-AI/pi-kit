# artifacts-feature-artifacts

`@pi-kit/artifacts/feature-artifacts`, library type `type:feature` of the `artifacts` domain (tags `scope:artifacts`, `type:feature`).

A lazy entry: container components wired to the stores, one per lazy chunk. May use `feature`, `ui`, `data`, `util` of this domain, `scope:shared`, and the `api` of other domains.

The boundary rules are in `eslint.config.mjs` at the repository root; `doc/docs/structure.md` has the tree and the rule per type.
