# session-tree-api

`@pi-kit/session-tree/api`, library type `type:api` of the `session-tree` domain (tags `scope:session-tree`, `type:api`).

What other domains may import: a facade over the domain&#39;s store and selected types. May use this domain&#39;s `data` and `util` and `scope:shared`.

The boundary rules are in `eslint.config.mjs` at the repository root; `doc/docs/structure.md` has the tree and the rule per type.
