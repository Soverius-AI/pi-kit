# session-tree-data

`@pi-kit/session-tree/data`, library type `type:data` of the `session-tree` domain (tags `scope:session-tree`, `type:data`).

The SignalStores, direct generated API operations and mappers. May use `data`, `util`, `scope:shared` and the `api` of other domains.

The boundary rules are in `eslint.config.mjs` at the repository root; `doc/docs/structure.md` has the tree and the rule per type.
