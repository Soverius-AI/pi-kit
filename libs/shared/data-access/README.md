# shared-data-access

The store traits (`withRequestStatus`, `withLatestRequest`, `withPolling`, `withPersistence`, `withSelection`,
`withBackendEvents`), the stores every domain uses (toasts, dialogs, theme, view prefs, UI switches, health, provider usage,
redaction, clock) and the injectable renderer policies (`RENDERER_POLICY`, `CONTEXT_POLICY`, `IS_MAC`). Generated operations
and the HTTP transport are `@pi-kit/api`. Tags `scope:shared`, `type:data`; alias `@pi-kit/data-access`.
