# threads-ui

`@pi-kit/threads/ui`, library type `type:ui` of the `threads` domain (tags `scope:threads`, `type:ui`).

Presentational components: inputs and outputs only, no store, no HTTP. May use `ui`, `util` and `scope:shared`.

The boundary rules are in `eslint.config.mjs` at the repository root; `doc/docs/structure.md` has the tree and the rule per type.
